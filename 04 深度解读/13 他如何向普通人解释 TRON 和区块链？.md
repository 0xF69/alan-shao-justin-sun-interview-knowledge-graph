# 他如何向普通人解释 TRON 和区块链？


视频位置：01:32:20—01:49:00

邵艾伦提出，希望孙宇晨用普通人容易理解的方式介绍 TRON 到底在做什么。

孙宇晨给出了一个很有意思的解释：

他认为，区块链正在尝试将货币变成互联网和机器能够直接理解、处理的体系。

他把这种变化与数学形式化证明联系起来。

传统数学证明往往使用自然语言与数学符号表达，而形式化证明试图通过严格的形式系统，让计算机能够验证推导过程。

他认为，两者的共同之处，在于把原本主要依赖人类理解的对象，转变为可以由机器执行和验证的对象。

### 深层解读：重点在于可编程性和可验证性

在货币领域，区块链让部分资产转移和交易规则能够通过程序执行与验证。

在数学领域，形式化工具可以帮助检查证明是否符合既定逻辑规则。

孙宇晨认为，这种机器可以直接处理的形式，将在 AI 时代变得更加重要。

不过，需要指出，他在访谈中把去中心化与机器可读性联系得过于绝对。

实际上，传统支付系统也可以通过 API 实现机器调用。区块链的差异更多在于账本结构、信任机制、可组合性、开放程度及结算方式，而不是传统数字支付完全不能被机器理解。
