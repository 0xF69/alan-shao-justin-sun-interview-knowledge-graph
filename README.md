# 邵艾伦 × 孙宇晨访谈知识图谱

把四小时访谈整理成可以沿着主题、概念、时间轴和论证关系阅读的知识库。保留嘉宾观点、整理者的解读、论证辨析和背景来源，方便回到原始材料核对。

包含 72 个图谱节点、152 条语义关系、64 个概念、26 段时间轴、32 篇深度解读、12 篇辨析、11 张背景研究卡片和 15 张 Canvas。

## 怎么打开

### Obsidian

1. 下载仓库 ZIP 并解压，或运行：

   ```bash
   git clone https://github.com/0xF69/sungemode-knowledge-graph.git
   ```

2. 在 Obsidian 中选择「打开文件夹作为仓库」，打开下载后的文件夹。
3. 从 [开始阅读](00%20导航/开始阅读.md) 进入。

无需第三方插件。笔记使用 Obsidian 双向链接，图谱使用内置 Canvas。GitHub 可以阅读 Markdown 正文；Obsidian 双向链接和 Canvas 建议在 Obsidian 中查看。

### 浏览器

下载后，用浏览器打开 [交互式知识图谱 HTML](07%20原始材料/孙宇晨访谈_交互式知识图谱.html)，可以搜索节点、切换视图、查看关联、拖动画布和缩放。HTML 内嵌图谱数据，无需安装依赖。

## 核对与修改
